Gitee / 其他 Git 服务认证

公开仓库无需填写。克隆 Gitee 等服务的私有仓库时，在这里填写该服务的 Git HTTPS 用户名和密码 / 访问令牌（两项都填）。如果服务不接受账户密码，请使用它提供的 Git 访问令牌。

GitHub 账户登录密码不能用于 Git HTTPS。启用了两步验证（2FA）的 GitHub 账号，请使用下方 GitHub App 授权；也可以把 GitHub 访问令牌填在这里作为密码。凭据只在本次克隆期间保存在页面内存。

GitHub 私有仓库授权（启用 2FA 推荐）

公开仓库无需登录。克隆 github.com 私有仓库时，启用了 2FA 的账号推荐使用此授权方式。首次使用请在 GitHub → Settings → Developer settings → GitHub Apps → New GitHub App 创建 App，启用 Device Flow，并将 Contents 权限设为 Read-only。

复制 App 设置页中的 Client ID（不是 App ID）并粘贴到这里。点击“连接 GitHub”后，打开授权页面输入一次性验证码，再完成登录和 2FA。授权只用于 GitHub。
